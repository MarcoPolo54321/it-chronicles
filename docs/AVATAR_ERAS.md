# Профили героев и смена эпох

В игре доступно 13 профилей. Игрок выбирает профиль при создании карьеры, а изображение меняется по ходу кампании:

- `2000.webp` — 2000–2009 годы;
- `2010.webp` — финальный 2010 год и свободный режим после завершения кампании.

Файлы находятся по адресу:

```text
www/assets/avatars/heroes/<avatar_id>/<era>.webp
```

Например:

```text
www/assets/avatars/heroes/classic/2000.webp
www/assets/avatars/heroes/classic/2010.webp
```

Чтобы обновить рисунок, замените соответствующий WebP без переименования. Рекомендуемый формат — квадрат 768×768.

Старые идентификаторы профилей сохранены. Выбранный герой и накопленный фон также учитываются в «Новой игре+».
