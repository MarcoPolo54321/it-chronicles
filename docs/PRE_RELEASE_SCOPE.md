# Покрытие предложений в v0.16.7

Реализованы недельная ротация быстрых материалов, временные знания для книг, форумов, курсов и лекций, скрытие недоступных источников, подключение 16 новых изображений заказов, компактные карточки заявок, сворачиваемые детали ремонта, исправления светлой темы, упрощённая «База героя», свёрнутые карьерные направления и сокращённое окно улучшения рабочего места.
