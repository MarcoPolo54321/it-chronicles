Хроники Айтишника 0.17.2 — исправление сборочных зависимостей

Причина предыдущей ошибки:
- @capacitor/android@7.1.2 не существует в npm-реестре пользователя.
- Из-за этого npm завершался с ETARGET до создания Android-проекта.

Исправлено:
- зависимости Capacitor возвращены к совместимому диапазону ^7.0.0, который уже успешно собирал версии 0.17.0 и 0.17.1;
- удалена неверная фиксация несуществующей версии;
- проверка node_modules теперь принимает любую совместимую версию 7.x;
- после установки сборщик выводит фактически установленные версии Capacitor;
- android/local.properties создаётся только после создания Android-проекта.

Сборка:
1. Распаковать ZIP в новую пустую папку.
2. Не выполнять вручную команды создания android/local.properties.
3. Запустить .\BUILD_UPDATE.bat
