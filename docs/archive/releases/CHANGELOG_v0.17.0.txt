Хроники Айтишника — версия 0.17.0

ПИТАНИЕ
- Ежемесячные цены заменены дневными.
- Домашняя еда: бесплатно.
- Кафе / перекус: 60 ₽ за день.
- Заводская столовая: 120 ₽ за день.
- Шашлычная: 300 ₽ за день.
- Недорогой ресторан: 700 ₽ за день.
- Хороший ресторан: 1 200 ₽ за день.
- Доставка еды: 900 ₽ за день.
- Оплата списывается один раз за игровой день с учётом коэффициента года.
- При нехватке денег герой автоматически переходит на домашнюю еду.

ИНТЕРФЕЙС
- Удалён блок «Сейчас в фокусе» на главной странице.
- «Барахолка» вынесена из мастерской в отдельный пункт меню «Ещё».
- В мастерской остались: место, инструменты, комплектующие, склад и сборка ПК.

НАВИГАЦИЯ
- Android-кнопка и жест «Назад» закрывают открытое окно.
- Из подразделов «Ещё» кнопка возвращает к общему списку пунктов.
- Из основных разделов кнопка возвращает на главную.
- Подтверждение выхода появляется только с главной страницы.

СОБЫТИЯ
- На каждом варианте теперь показаны требуемые навыки и текущий уровень героя.
- Недоступные варианты блокируются заранее.
- При нехватке навыка выводится конкретное требование.
- При ошибке выбора событие остаётся открытым.
- Добавлен файл EVENT_STORIES_0.17.0.txt для подготовки иллюстраций.

СБОРКА
- BUILD_UPDATE.ps1 автоматически создаёт android/local.properties, если Android SDK установлен стандартно.
- Android versionCode: 1700.
- Android versionName: 0.17.0.
