# Архив служебных файлов

Здесь хранятся материалы прошлых версий, которые не нужны в корне проекта, но могут пригодиться для истории и технического аудита.

- `releases/` — текстовые changelog релизов;
- `manifests/` — манифесты состава сборок;
- `validation/` — отчёты проверок сборок;
- `audits/` — списки ассетов, источников рекламы, событий и другие служебные аудиты.
