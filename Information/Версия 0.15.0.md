# Версия 0.15.0

## Главное

- Фоновый ретро-микс встроен в игру и управляется через настройки.
- Рабочее место использует 10 полноценных сцен и более 120 новых иконок предметов.
- В мастерской появилась отдельная вкладка инструментов.
- Для каждого навыка добавлено по 10 одноразовых книг: прочтение даёт +1 уровень.
- Профильные заказы всегда начисляют XP соответствующим навыкам.
- Подключены изображения героев для трёх эпох.
