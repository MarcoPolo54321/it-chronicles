# Версия 0.14.2

## Что изменено

### Стартовые бонусы персонажей
- Все 13 профилей получили по два небольших стартовых бонуса.
- Каждый бонус повышает соответствующий навык на 1 уровень.
- Бонусы видны прямо в селекторе героя и в блоке подтверждения.
- Для существующих сохранений бонус выбранного профиля применяется один раз при первом запуске 0.14.2.

### Безопасный выход
- Нажатие системной кнопки «Назад» больше не закрывает приложение мгновенно.
- Появляется подтверждение: «Хотите ли вы закрыть игру?».
- Перед выходом профиль сохраняется.
- Для Android добавлен плагин `@capacitor/app`.

### Главный экран
- Старый верхний блок с отдельной иконкой, бегущей лентой и подписью режима удалён.
- Собрана единая карточка профиля: герой, имя, эпоха, год, навыковые бонусы и основные показатели.
- Блок выбора типа игры убран из создания карьеры.
- Новые карьеры запускаются в основной кампании.

### Лента эпохи
- Старые временные новости скрыты.
- Оставлен аккуратный подготовленный блок для будущего наполнения историческими новостями.
