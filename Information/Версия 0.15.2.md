# Версия 0.15.2

- Фоновая музыка немедленно приостанавливается при сворачивании, блокировке экрана и переходе приложения в фон.
- После возвращения в игру музыка возобновляется только при включённых настройках звука.
- Добавлено 48 курсов с автоматически рассчитанной оценкой сложности по 10-балльной шкале.
- Добавлено 48 тематических лекций начала 2000-х.
- Добавлено 36 техникумов и ПТУ с рейтингами подготовки по 10-балльной шкале.
- Добавлено 48 вузов по восьми направлениям с рейтингами подготовки по 50-балльной шкале.
- Добавлено 40 тематических форумов с рейтингами авторитета по 5-балльной шкале.
- Техникумы и вузы дают базу по всем направлениям, усиленную профильную подготовку и примерно половинную прибавку по ближайшим смежным дисциплинам.
- Старые дубли курсов, лекций, техникумов, вузов и форумов заменены единым каталогом 0.15.2.
- Схема сохранения остаётся v15; прогресс версии 0.15.1 не сбрасывается.
